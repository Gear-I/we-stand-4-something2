# We Stand 4 Something — website

Static recreation of [westand4something.org](https://www.westand4something.org/), built to be hosted on GitHub Pages.
On desktop it reproduces the original Wix layout; on phones the same content stacks into a single column.

## Pages

| URL | Page |
|---|---|
| `/` | Home |
| `/resources/` | Resources (sub-pages: `/legislation/`, `/feedback/`) |
| `/about/` | About / Board Members (bios: `/emmanuel/`, `/marissa/`, `/dielle/`, `/se/`) |
| `/services/`, `/events/`, `/blank/` (Support Us!), `/photo-gallery/`, `/shop/`, `/blog-1/` | Menu items under "More" |
| `/friday-feast/` | Friday Feast |

URLs match the old Wix site, so existing links keep working if the domain is pointed here.

## Editing

Pages are generated by `_build/build.py` — each page is a list of text, images and buttons with their positions.
Change the text there and run:

```sh
python3 _build/build.py
```

Styles live in `assets/css/site.css`. You can also edit the generated `index.html` files directly, but a rebuild will overwrite those edits.

## Notes

- Images are still loaded from the Wix image CDN (`static.wixstatic.com`). If the Wix site is shut down, download them into `assets/` first and update the URLs in `_build/build.py`.
- Forms (Feedback, Events registration, Services group sign-ups) open the visitor's email app with a message addressed to info@westand4something.org, since GitHub Pages can't process form submissions.
- The Events calendar is a simple month view (the original Wix calendar had no events listed).

## Custom domain

To serve this at westand4something.org: repo **Settings → Pages → Custom domain**, then point the domain's DNS at GitHub Pages.
